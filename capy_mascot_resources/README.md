# Capy Mascot Resource Pack

This pack separates the generated Soft 3D Capy mascot sheet into reusable reference images for design systems, UI concepts, and Claude-based design generation.

Folders:
- 01_hero — primary mascot artwork
- 02_poses — situational full-body poses
- 03_turnaround — character consistency/reference views
- 04_expressions — facial expression references

Also included:
- 00_master_character_sheet.png — original full sheet
- manifest.json — asset names, categories, crop boxes, and dimensions

Recommended use with Claude:
Use the master sheet plus the turnaround images as the source of truth for character consistency. Use hero/pose/expression/accessory images as supporting design references.
